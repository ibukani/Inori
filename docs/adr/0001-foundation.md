# ADR 0001: Rust基盤と交換可能な周辺機能

状態: 採用。GPUIは実機適合性の検証待ち。

長期常駐・状態管理・資源制御を重視し、Rustを実行核に採用する。
HTTPにAxum、非同期処理にTokio、保存層にSQLx/SQLiteを用いる。
Rustを採用しても論理競合・モデル誤認・権限ミスは防げないため、revision検査・
操作台帳・出典・権限ゲート・テストを別途実装する。

旧TypeScriptサーバー案とTauri/Reactクライアント案を置き換える。
TypeScriptは公開SDKで使用し、Pythonの拡張例を用意する。
GPUIのAPIを公開拡張や実行核へ露出させず、native Rust ABIを公開プラグイン境界にしない。
GPUIは=0.2.2へ固定し、Rust 1.95.0との組合せを検証する。

私有モノレポ内に独立したCargoプロジェクトを配置する。
リポジトリ、ビルド単位、実行プロセス、配布単位は一致させる必要がない。
依存ロックとCIにより、言語・OS・外部API更新による故障を検出する。
