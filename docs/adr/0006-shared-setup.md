# ADR 0006: 共通セットアップとOS常駐

日付: 2026-11-07。状態: 採用（ユーザー確認済みの実装計画）。

## 確定要件

利用開始と開発を簡単にする。Windowsアプリは初回画面、Windows/macOS/Linuxサーバーは対話式。
展開型配布、端末別接続ファイル、選択した場合のOS起動時常駐を提供する。
Linux初期対象はsystemdのUbuntu/Debian系x64。既存AI・音声エンジンへ接続し、自動導入はしない。
開発依存は検出・案内する。OS別インストーラー・署名・自動更新は対象外。

## 設計判断

- app-supportはGUI・音声・runtime・storageを参照せず、protocolと設定用I/Oだけを使う。
- setup/doctor/export-connection/serviceはCLIに置き、domainやruntimeへOS管理を入れない。
- 人格・記憶・自律活動はサーバーが所有する。アプリ別設定は接続先と端末認証を保持する。
- 接続設定は認証付きTLSの検証後に原子的に保存する。通常端末へ管理権限を付与しない。
- POSTの端末発行は管理者限定。DBはトークンのハッシュだけを保存し、公開契約から型を生成する。
- キーは保護した別ファイルへ保存し、環境変数を優先して明示注入する。API・Debug・ログで値を公開しない。
- 常駐はWindows LocalService／Unix専用非ログインアカウント。バイナリは管理者所有の固定場所へ置く。
- 配布はアプリ宣言の許可リストを使い、作業ディレクトリ・実データを再帰的に取り込まない。
- 選択済みモデルの自動切替やデータの自動移動はしない。移行は停止・バックアップ後の明示操作。

## 仮定と未検証事項

設計上の基準はWindows x64、macOS Intel/Apple Silicon、Debian 12ビルド・Ubuntu 24.04互換性。
CI定義は実行成功を意味しない。常駐登録・再起動・クリーン環境・GUI操作はstatusへ実施結果を分けて記録する。
GPUI採用ゲート、音声性能、長時間運用の既存未検証条件は維持する。
