# GPUIの採用ゲート

ユーザー確定事項（R17）として、実行時の負荷・メモリ使用量の抑制を重視し、WindowsクライアントはGPUIで継続開発します。
この選定方針と、実機適合性の合格・本採用は区別します。[ADR 0004](../adr/0004-gpui-resource-priority.md) を参照してください。

GPUI 0.2.2 と gpui-component 0.5.1 を固定した検証用クライアントです。
現在の画面は単一時系列のチャットと接続設定、音声トグル、トレイを備える試作です。画像・キャラクター描画と管理画面はありません。
下記の重大な未検証項目が解決するまで、本採用・広いUI作り込みへ進めません。
サーバー側の開発と契約は独立して進められます。

| 項目 | 状態 |
|---|---|
| Windowsのネイティブビルド | `cargo check --workspace` と `cargo build --locked -p inori-desktop` 成功 |
| 日本語Unicode入力・送受信・表示 | 実画面で確認済み |
| IME変換中の確定・未確定・候補ウィンドウ位置 | 専用検証が必要 |
| チャット画面・接続設定 | 新しい画面は実装・ビルド済み。computer-use起動承認がタイムアウトし、実画面確認は未実施 |
| トレイ常駐 | 実装済み。閉じる操作は最小化。トレイの実操作は未確認 |
| 内蔵GPU・RAM8GB環境での実行 | 対象環境で未検証 |
| マイク・スピーカー・端末切替 | デバイスの列挙を確認。実際の入出力・端末切替は未検証 |
| 発話検出・エコー除去 | client-coreにearshot/sonora処理を実装。実機の認識精度・エコー除去効果は未検証 |
| 発話開始から再生停止150ms以下 | 未測定。T02の仮目標として実機測定が必要 |
| スリープ復帰・ネットワーク切替 | 再接続を実装、実機試験が必要 |
| デスクトップ透過・クリック透過・最前面の制御 | 未検証。現在は通常の不透明ウィンドウ |
| 24時間のGUI常駐 | 未検証 |

低負荷・省メモリの検証では、対象のRAM8GB・内蔵GPU環境でreleaseビルドを使い、
待機・表示・最小化・音声動作時のCPU、Working Set、Private Bytes、GPU使用量を記録します。
ハードウェア、ビルドプロファイル、AI・音声・rendererの稼働状態、サンプル時間を併記し、
外部プロセスの使用量も分けて報告します。T03のクライアント300MB・実行核200MBは対象環境での達成未確認の仮目標です。
不要な再描画・ポーリングや非表示時のアニメーション等の削減は今後の最適化方針であり、完了済みとは扱いません。

透過表示やIME・ドライバーに未解決問題が残れば、まずGPUI内での修正・最適化を検討します。
解決できない重大な問題は実測結果と制約を提示し、UIの作り込みを止めます。
`client-core`と公開契約を維持し、選定方針の変更が必要なら根拠を別ADRで提案します。
Tauriへの移行・比較試作は現行計画に含めません。他UI方式との性能の優劣は未検証です。
