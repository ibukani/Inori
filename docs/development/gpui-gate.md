# GPUIの採用ゲート

GPUI 0.2.2 と gpui-component 0.5.1 を固定した検証用クライアントです。
現在の画面は会話・記憶編集・接続と人格設定・個別権限・簡易2Dまでの試作とします。
下記の重大な未検証項目が解決するまで、本採用・広いUI作り込みへ進めません。
サーバー側の開発と契約は独立して進められます。

| 項目 | 状態 |
|---|---|
| Windowsのネイティブビルド | 確認済み |
| 日本語Unicode入力・送受信・表示 | 実画面で確認済み |
| IME変換中の確定・未確定・候補ウィンドウ位置 | 専用検証が必要 |
| 会話の表示・記憶の訂正・設定画面 | 実画面で確認 |
| トレイ常駐 | 実装済み。閉じる操作は最小化 |
| 内蔵GPU・RAM8GB環境での実行 | 対象環境で未検証 |
| マイク・スピーカー・録音中の端末切替 | デバイスの列挙を確認。実際の入出力・端末切替は未検証 |
| 発話検出・エコー除去・150ms割り込み | 未実装／未測定。現在はボタン式録音 |
| スリープ復帰・ネットワーク切替 | 再接続を実装、実機試験が必要 |
| デスクトップ透過・クリック透過・最前面の制御 | 未検証。現在は通常の不透明ウィンドウ |
| 24時間のGUI常駐 | 未検証 |

透過表示やIME・ドライバーに未解決問題が残れば、`client-core`と公開契約を維持し、
egui / Slint / OSネイティブUI等の候補を同じ入力・描画・メモリ条件で比較するADRを追加します。
置き換え候補の性能はまだ比較測定していません。
