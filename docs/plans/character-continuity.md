# 人格と会話の継続性の段階実装

2026-11-07。ユーザーが承認した実装方針。要件はR01/R04/R10/R21を参照する。
同時に進める段階は一つだけとし、各段階で動作検証、同条件の実AI比較、ユーザーによる会話確認を行う。

更新: R22により実装の合否とモデル応答の観測を分離する。禁止文やモデル固有の補正を極力増やさず、
第1段階の[対話処理の簡素化](dialogue-simplification.md)を実装する。人物像の採否は引き続きユーザーが確認する。

## 第1段階: 一回の会話で本人の性格が伝わる

好奇心と率直さを強く、遊び好きで、最初から気軽な友人。特定の趣味は固定しない。
人間が書いた作品から反応の原則を分析し、人格候補・参照場面・採用理由を確認可能にする。
人格は既存のpersonaで渡し、対話モジュールは特定人物に依存しない会話方針と文脈選択を担当する。
現在の入力、基本人格・最小限の応答方針、直近の会話、追加の記憶の順で予算を確保する。

実装: 対話方針、原記録IDによる現在入力の識別、往復単位の履歴選択、12場面の実AI比較と採点ツール。
人格本文は候補として分け、保存済みの人格や本番設定は自動変更しない。
作品分析・人格候補の採否と、実際の会話はユーザー確認待ち。モデルの品質観測を実装の不合格とは混同しない。
詳細は [人物像と出典](../character/inori.md)、[検証と実行手順](../development/dialogue-review.md)。

## 第2段階: 興味が次の会話へ続く（未着手）

第1段階の合格後に着手する。サーバーが最大3件の一時的な関心を所有し、
話題、Inoriが気にする点、次の着眼点、原記録、公開範囲、日時、revisionを保存する。
基本人格、ユーザーの事実、一時的な関心を分離する。

既存の背景整理を完了した会話と関心を読める形へ拡張し、記憶候補・関心更新・処理済み記録を
一つのトランザクションで確定する。古いrevisionと抑制した根拠を拒否し、変更履歴と再生成抑止を持つ。
管理API `/v1/conversation/interests` とID配下に一覧・訂正・削除を追加する。
通常の記憶訂正・削除でも関連する関心を無効化する。

合格条件は、関連する返答・再会の挨拶で自然に続きを選べること、再起動をまたぐこと、
無関係な時には差し込まないこと、訂正・削除が派生状態にも反映されること。

## 第3段階: 同じ興味から自分で話しかける（未着手）

第2段階の合格後に着手する。同じ関心を使い、既存の自律モジュールが話すか見送るかを判断する。
認証済み端末・セッションに結び付けた `/v1/conversation/availability` を追加する。
会話可能、入力中、発話検出中、画面表示中という状態のみを15秒ごとに更新し、45秒で失効する。
配信先は会話可能な一つのセッションに限定し、旧クライアントへ開始しない。

開始理由が自発発話であるターンを追加し、架空のユーザー発言を保存しない。
入力開始・切断・状態変更で中断し、送信直前に根拠と状態を再検査する。
再接続・再起動で二重送信しない。チャットに音声と独立した自発会話トグルを追加し、初期OFFにする。

仮初期値: 最後の会話または自発発話から30分以上、1日最大6回、無返信は連続2回まで。
展開のない同じ話題を繰り返さず、既存の背景予算とクラウド設定に従う。

## 共通の品質ゲート

各段階で12場面を固定し、同じモデル・設定で改修前後を各3回比較する。
人格の一貫性、自然さ、継続性、開始の適切さからその段階に適用する項目を評価する。
モデル評価の仮目安は各項目平均4/5以上、比較の3分の2以上で改修版を支持。
モデルの捏造や言葉遣いの揺れは観測として残し、点数から実装合格やユーザー承認を自動決定しない。
実装は入力・状態・権限・保存の検査で判定する。捏造を確認済み情報として保存する、削除内容を復活させる、
私的情報を公開入力へ渡す問題は実装上の不合格。Auto等の変更で出力上限が異なる比較は、その差を明示する。

最初は私的なテキスト会話を対象とする。音声表現、感情全般、関係性の成長、公開・配信、外部活動は後続。
GPUI採用ゲート、実音声、対象機、OS別導入、長時間検証は独立した未完了事項として維持する。
