# 運用

`windows/register-server.ps1` は本人が実行した場合のみログオン時タスクを登録します。
本実装では自動登録していません。ログアウト中も動かすWindowsサービスの導入は後続です。
サーバーはGUIを必要としないため、常時稼働する別PCで実行できます。
macOSは同じバイナリのCLIで運用し、launchdへの組み込みは利用環境で設定します。

配布時は署名・更新チャネル・インストーラーを追加してください。DB更新前にバックアップと別領域への復旧を確認します。
自宅LAN/VPN限定です。ルーターのポート転送や一般公開は初期範囲に含めません。
端末に配るのは端末用トークンと公開証明書です。サーバー秘密鍵やownerトークンを他端末へ共用しないでください。
