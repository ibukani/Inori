# Inori デスクトップ

`inori-desktop.exe` を起動し、「接続用ファイルを選択」でサーバーから渡されたファイルを開きます。
接続先と証明書を確認して「接続して保存」を押してください。次回から同じ設定を使います。
Rust・Python・Node.jsは不要です。同じPCの従来のローカル接続も利用できます。

接続用ファイルは端末認証情報を含みます。保存したアプリ設定も含め、他の人へ公開しないでください。
接続設定はOSのアプリ設定領域へ保存します。接続失敗時は設定画面から再設定できます。
従来の `--config`、URL・トークンファイル・証明書の指定も利用できます。

マイクとAI音声は起動時OFFです。ウィンドウを閉じるとトレイに隠れ、Ctrl+Qまたはトレイの「終了」で終了します。
サーバーは独立して稼働します。このアプリに人格・記憶・モデルの管理画面はありません。

GPUIの適合性検証用の試作です。対象8GB・内蔵GPUでの適合、実音声と24時間常駐は別途検証が必要です。
