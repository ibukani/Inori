# 表示の拡張

組み込み `basic-2d` は GPUI による簡易キャラクターです。画像を使う場合は
`contracts/v1.json` の `ModelPack` を満たす JSON を `--model-pack` で指定します。
`expressions.idle` は JSON と同じディレクトリ以下の画像の相対パスです。
他ディレクトリへの参照・4MBを超える素材は拒否します。現在は idle 表情のみ読み込みます。

`PresentationState` は表示への要求の公開契約です。Live2D・3D用の外部描画プロセス、
表情切り替え、独立ウィンドウとの同期は後続実装です。GPUI 型を拡張契約に含めません。
素材のライセンス欄は作者が記載し、素材と描画 SDK の配布条件を別々に確認します。
